# Foyer

`/` —— 房间的前门。一屏，不滚动，只有一个入口：**INTRARE** → `/room`。

日子的数、今天的天、此刻的月相、当季挂的画都在这一屏上；再往里才是六个房间。想直接进屋子的，在设置里勾掉它。

---

## 四屏

两个轴相乘：**昼夜**（`kimi-theme` cookie，全站共用，`/room` 也跟着变）× **构图**（`kimi-foyer` cookie，只管这一页）。

| | 满窗 · PLENA | 三联 · TRIA |
|---|---|---|
| **昼** | 侧幕花柱：两幅花panel 从左右印进奶油纸里，中间一道手绘拱门 | 三扇窗龛挂《四季》：左是当季、右是下一季，中间恒定 ROSA |
| **夜** | 满窗彩窗：一整扇铺满，透光随窗色，金尘缓落，四角鎏金卷叶 | 三联彩窗：同样的窗切成三片，一拱一片 |

右下角两枚圆印各切一个轴。印上画的是**点下去会到的地方**，不是当前状态：昼里显月纹 · NOX，夜里显日纹 · DIES；满窗时显三拱 · TRIA，三联时显单拱 · PLENA。

## 手势

- **左右划**：夜里换一扇彩窗，昼里换一对花。不划的话每天自己换一次（本地日历天，当地午夜翻）。
- **点两侧**：昼 · 满窗那一屏，点左右任一条花柱也翻。
- 这一屏不滚动，所以下拉刷新在这里是关掉的 —— 否则往下划一点就会刷新页面。

## 设定

都在 `/backstage/settings` 的「门厅」一节，存在你自己的浏览器里（`localStorage`）。

| 项 | 存储键 | 说明 |
|---|---|---|
| 起算日 | `kimi-foyer-since` | 门厅上那个数从这天算起，当天是 0。留空 = 第一次打开门厅那天，自动记下 |
| 那句话 | `kimi-foyer-quote` | 一行一个换行，断行就是排版 |
| 门口便签 | `kimi-foyer-note` | 压在 AD ALTERUM · P.S. 底下那张小纸片 |
| 天气 | `kimi-foyer-weather` | `{label, lat, lng}`。走 Open-Meteo，不要 key；留空整行不显示 |
| 跳过门厅 | `kimi-foyer-skip` cookie | 勾上之后打开网址直接进 `/room` |

名字读的是同一页上面的「TA 的名字」/「你的名字」（`{{char}}` / `{{user}}` 那两个），肖像读「头像」一节上传的两张。没上传就是两枚空环 —— 环本身就是位置。

时间全部按**这台设备的本地时钟**算：天数、拉丁问候（NOX SERENA / AVE · AURORA / POST MERIDIEM / VESPER）、拉丁日期、百日碑、月相、今天该挂哪张画。服务端只从 cookie 决定渲染哪一屏，内容等页面挂载后才算 —— 所以第一帧是一层同色底，不是错的时区。

## 换成你自己的画

素材在 `public/images/foyer/`，注册表在 `src/lib/foyer.ts`：

```ts
// 昼 · 满窗那两条花柱，每天轮一张。两个数组一一对应。
export const FLOWER_PANELS = ["/images/foyer/mucha-a1.webp", …];
export const FLOWER_NAMES  = ["CONVALLARIA", …];

// 昼 · 三联两侧的四季，走到哪一季挂哪一季。
export const SEASON_PANELS = [{ src: …, name: "VER" }, …];

// 夜 · 两屏共用的彩窗。light 是透光色 "R,G,B"，采自那扇窗的主导色相。
// pieces 给三联用：三片切好的 [左, 中, 右]；没有就三拱各裁一张整窗。
// bg 是有 pieces 时的底色，取图里的黑，让三片与暗底接得上。
export const WINDOW_PANELS = [
  { src: …, name: "金焰窗", light: "240,190,90" },
  { src: …, name: "…", light: "119,108,216", pieces: [l, c, r], bg: "#000000" },
];
```

花柱裁成 242×1008 —— 这个比例是龛的形状，不是画的形状，所以太长的顶对齐切下摆、太宽的居中收窄。彩窗给整张就行。数组长度随便加，轮换按长度取模。

### 自带的这几张是谁的

- 花柱与《四季》是**慕夏（Alphonse Mucha, 1860–1939）**1890 年代的装饰版画，已进公有领域。
- 夜里那扇多格叙事的窗，是**慕夏为布拉格圣维特大教堂新大主教礼拜堂设计**的彩窗，1930 年作、1931 年装。玻璃本身公有领域，照片的摄影者不明。
- 另一扇金黄底的窗是**夏加尔（Marc Chagall, 1887–1985）**的作品，**至 2055 年前后仍在版权保护期内**。它作为非商用的默认素材附在这里；**要商用部署的 fork 必须换掉它**，或者直接从 `WINDOW_PANELS` 里删掉那一条——剩下圣维特那扇照常轮换，别处一个字都不用改。

完整的版权说明在 [NOTICE.md](../NOTICE.md)。

## 已知的边界

- 季节按北半球的月份分（3–5 春）。南半球把 `getSeasonIndex()` 里那个 `3` 改成 `9`。
- 舞台设计基准 402×874，比这窄的屏定宽居中、不等比缩，所以很矮的屏上底部会挤，很高的屏上底部会空。
- 拉丁文里 U 写作 V（VESTIBVLVM 那一路的写法），这是刻意的。
